# Smart Parking Assistant using Arduino

## Project Overview
This project helps drivers park safely by measuring the distance between the vehicle and obstacles using an ultrasonic sensor.

## Features
- Measures distance in centimeters.
- Displays distance on an LCD screen.
- Uses RGB LEDs to indicate safety levels.
- Produces audio alerts using a buzzer.
- Shows STOP warning when the obstacle is too close.

## Components Used
- Arduino Uno
- Ultrasonic Sensor (HC-SR04)
- LCD Display
- RGB LED
- Buzzer
- Jumper Wires
